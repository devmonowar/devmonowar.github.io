Free Widgets For Elementor — the missing widgets, nothing else

By Monowar Hossain 12 September 2026

Summary. Free Widgets For Elementor adds the widgets the free core leaves out — pricing table, flip box, team, call to action, countdown timer, post grid, logo carousel and table of contents. Each one loads its files only where it is used, any of them can be switched off, and there is no Pro version.

The wall free Elementor hits

Build enough sites with free Elementor and the moment comes: you need a pricing table, or a flip box, or a plain countdown timer, and the free core simply does not have them. The standard fix is a giant addon pack — dozens of widgets installed for the three you actually wanted, every one of them loading on pages you will never put them on.

This plugin is the opposite bet: only what the free core is missing, nothing it already has, nothing you will not use. The free version of Elementor is enough. Pro is not required for a single thing in it.

What is inside

  • Pricing Table — header, price, feature list, button, with an optional featured highlight
  • Flip Box — a 3D flip to a back face with a call to action, on hover or click
  • Team — photo, role, bio and social links for member cards
  • Call To Action — title, text, button and background in one styled box
  • Countdown Timer — counts down to a date and time, with a message for when it expires
  • Post Grid — image, title, meta, excerpt and read-more in a responsive grid
  • Logo Carousel — arrows, dots and autoplay, responsive out of the box
  • Table of Contents — an auto-generated outline with smooth scroll and scrollspy

One thing is missing on purpose: there is no testimonial widget here. Testimonials need a post type, groups and a submission form, which is a whole plugin — my Advanced Testimonial — not a widget.

Only where it is used

The reason a small list stays small in weight too: each widget's CSS and JavaScript load only on pages where that widget sits. And if you know you will never use one, its toggle removes it completely — a disabled widget is never even registered with Elementor, let alone loaded.

FAQ

Why these widgets and not more?
Each one fills a gap in Elementor's free core. Nothing here duplicates a widget Elementor already gives away, which is why the list stays short on purpose.
Why is there no testimonial widget?
Testimonials need a post type, groups and a submission form — that is a whole plugin, not a widget. It already exists separately as Advanced Testimonial.
Do widgets I don't use still load their files?
No. Each widget's CSS and JavaScript load only on pages where that widget is actually used, and any widget can be switched off entirely.
Can I switch off widgets I don't need?
Yes. Every widget has its own enable toggle, and a disabled widget is never even registered with Elementor.
Is there a Pro version?
No. The plugin is free with no upsells, reviewed by the WordPress.org team before release.
