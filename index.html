What I build

Plugins on WordPress.org

Each one started as a real problem on a real site, not as an idea for a product. All free, all GPL, all reviewed by the WordPress.org team before release.

  • General Slider

    A slider built on the lightweight Splide engine — no jQuery, accessible by default, and its CSS and JavaScript load only on pages that actually show a slider.

    WordPress.org GitHub Guide

  • Advanced Testimonial

    A plugin built only for testimonials — several display layouts and card styles, a front-end submission form, and Schema.org review markup so Google can show star ratings.

    WordPress.org GitHub Guide

  • Free Widgets For Elementor

    The widgets Elementor's free core is missing — Pricing Table, Flip Box, Countdown Timer and more — without a giant addon pack or an upgrade prompt.

    WordPress.org GitHub Guide

  • Janitorix Media Audit

    Proves an image is unused before it recommends deleting it. Confidence and risk are scored separately, and the evidence behind every verdict is there to inspect.

    WordPress.org GitHub Guide
