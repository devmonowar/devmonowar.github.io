A problem with one of my plugins

Please use the support forum on WordPress.org rather than email. It is faster for you, and the answer stays public so the next person with the same problem can find it.

  • General Slider Support forum
  • Advanced Testimonial Support forum
  • Free Widgets For Elementor Support forum

It helps a lot if you include: your WordPress version, the plugin version, which theme you are using, and a screenshot of what you are seeing. That usually turns three messages back and forth into one.
