Privacy Policy

Last updated 20 September 2026

This website collects nothing

devmonowar.github.io is hand-written static HTML. There is no analytics, no JavaScript, no cookies, no contact form, and no account system — so there is nothing here that records your visit. The site is hosted on GitHub Pages; like any web host, GitHub may keep server logs. Their policy governs that, not this page.

The WordPress plugins, on your own site

My plugins run on sites you control, and what they record stays there:

  • General Slider, Advanced Testimonial, Free Widgets For Elementor, Janitorix Media Audit — no visitor data leaves your site. Janitorix scans your own media library and stores its verdicts in your own database.
  • CrawlWatch - AI Bot Insights — logs visits from AI crawlers (time, bot name, visited URL, referrer, truncated user-agent). IP addresses are anonymised before hashing (IPv4 last octet and IPv6 /64 removed) and never stored raw. Logs are kept 7–180 days at your choice (30 by default) and auto-deleted; everything is removed on uninstall if enabled in Settings. No visitor data leaves your site.
  • ScheduleLens - Cron Viewer & Manager — stores its paused-jobs list, the last 100 run-log rows, custom intervals and three settings in your database. The only network call is a loopback check to your own site for the health tab. All data is deleted on uninstall if enabled in Settings.

One exception, on your side of the screen: opening a plugin's Demo Library in wp-admin fetches demo files from GitHub Pages, so GitHub sees that request like any web host would. It only happens when you open that screen, and nothing about it comes back to me.
