Alo Blog, my first WordPress theme

By Monowar Hossain 30 September 2026

Summary. Six plugins in, I built the thing plugins sit on top of: a theme. Alo Blog is a free, lightweight writing theme — single column, sidebar, no builder, no slider, no upsells. Why a theme after six plugins

Plugins live inside somebody else's design. Every support question I have answered this year eventually turned into a theme question — "it looks broken with my theme", "my theme loads jQuery on every page", "my theme has no sidebar on mobile". After the sixth plugin, I wanted to see the other side of that conversation.

So I set one rule before writing anything: the theme must be the kind of theme I would recommend to the people asking those questions. Fast, readable, accessible, and quiet. If a feature needed a settings page to explain itself, it did not go in.

What the theme review checks that the plugin review does not

I have been through the plugin review, so I expected the drill: prefixes, sanitizing, no phoning home. The theme review has all of that, plus a second layer nobody warns you about — presentation. Reviewers actually read your theme like a visitor: long titles that wrap and break layouts, submenus you cannot reach by keyboard, floats that never clear, editor styles that look nothing like the front end.

The fixes that came back were things like accessible submenus, title wrapping, float clearing, a real RTL stylesheet, and expanded editor styles. None of them would fail a code scanner. All of them show up on a real site. That is the difference: the plugin review asks "is this safe", the theme review also asks "is this finished".

What is inside Alo Blog

  • Single-column reading list with a right sidebar on blog and single posts — the layout most personal blogs actually need
  • Accessibility-first: skip link, visible focus, keyboard-operable menus, screen-reader labels
  • Reader-first typography: 720px measure, 17px system-font stack, generous line-height — no webfont downloads
  • Writer-friendly details: sticky featured posts, author box with avatar, tag pills, reading progress bar
  • Block-ready: editor styles that match the front end, an accent quote style, three starter patterns
  • Privacy-respecting: zero external requests, zero tracking, zero bundled scripts

Four options, not a dashboard

Appearance, Customize, Theme Options holds exactly four things: footer credit text, page sidebar position, excerpt length, and author box visibility. Themes that ship a hundred options are shipping a hundred decisions the author refused to make. I made mine.

FAQ

Is Alo Blog really free?
Yes. No Pro version, no locked features, no upsell screens. The whole theme is on WordPress.org under GPLv2 or later, same as my plugins.
Does it work with the block editor?
Yes. Editor styles match the front end, there is an accent quote style, and three starter patterns. It is a classic hybrid theme, not a block theme, so the Customizer still works.
How is the theme review different from the plugin review?
The plugin review is mostly security and guideline checks on your code. The theme review goes further into presentation: title wrapping, float clearing, submenu accessibility, RTL stylesheets, editor styles. Expect feedback on things a visitor sees, not just things a scanner flags.

Conclusion

A theme is a promise about taste, not just code — every default is a decision the user never has to make. Alo Blog is mine: quiet, fast, and finished. If you write on WordPress and your theme feels heavier than your words, try it.
