How to install Free Widgets For Elementor: the widgets Elementor's free core does not include

By Monowar Hossain 10 August 2026

Summary. Elementor's free version is good, but it is missing a few widgets almost every site ends up needing — a pricing table, a flip box, a countdown timer, a team section. I built Free Widgets For Elementor to fill exactly those gaps, with no bloat and no upsells. Here is how to install it and what each widget does.

The problem

If you have built more than a couple of sites with the free version of Elementor, you have hit this wall. You need a pricing table, or a flip box, or a simple countdown timer, and the free core just does not have them.

The usual fix is installing a giant all-in-one addon pack that ships dozens of widgets when you need three — slowing the site down with unused CSS and JavaScript on every page.

The solution

I built Free Widgets For Elementor as a focused, lightweight plugin that adds only the widgets Elementor's free core is actually missing. Nothing you already have, nothing you will not use.

It is fully free and GPL licensed, with no Pro version, no licence key, and no upgrade nags in the editor. Each widget's CSS and JavaScript load only on the pages where that widget is actually used, so it does not add weight to pages that do not need it.

Requirements

  • WordPress 6.0 or later
  • PHP 7.4 or later
  • Elementor — the free version. Elementor Pro is not required.

Step-by-step installation

  1. Make sure the free Elementor plugin is installed and activated on your site.
  2. In your WordPress dashboard, go to Plugins → Add New and search for Free Widgets For Elementor.
  3. Click Install Now, then Activate.
  4. Open any page in the Elementor editor. A new Free Widgets category appears at the top of the widgets panel.
  5. Drag any widget onto your page and start customising it.

Every setting sits in the normal Elementor sidebar, so there is nothing new to learn, and all the widgets are built to work inside Elementor's flexbox and grid containers.

Using the demo library

Instead of building sections from scratch, the plugin includes an optional Demo Library — a one-click way to import ready-made Elementor sections, images included, built with these widgets. New demos are added over time without needing a plugin update.

To use it, open the plugin's Demo Library screen from the WordPress admin, browse the available sections, and click Import on the one you want. If you are curious how that works under the hood, I wrote about it in the demo library case study.

Common mistakes to avoid

  • Installing without Elementor active. This plugin extends Elementor, so the free Elementor plugin has to be installed and active first.
  • Expecting a Pro upsell. There is not one. If a widget looks locked, that is not this plugin — double check which plugin you installed.
  • Assuming it needs Elementor Pro. It does not. Everything works on the free version.

FAQ

Does this plugin require Elementor Pro?
No. It only requires the free version of Elementor.
Will it slow down my site?
No. Each widget's CSS and JavaScript load only on the specific pages where that widget is used.
Is it really free forever?
Yes. No Pro version, no licence key, no locked features.
Does it work with Elementor's flexbox and grid containers?
Yes, all the widgets are built to work inside Elementor containers.
I activated the plugin but I do not see the "Free Widgets" category. What is wrong?
This almost always means the free Elementor plugin is not active yet. Activate Elementor first, then reload the page editor — the category will appear at the top of the widgets panel.

Conclusion

If you have ever reached for a bloated all-in-one addon pack just to get one pricing table or countdown widget, Free Widgets For Elementor is meant to be the lighter alternative — the widgets Elementor's free core is missing, and nothing else.
